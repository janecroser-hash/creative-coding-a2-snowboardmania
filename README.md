







Snowboardmania is a simple 2D game that is entertaining for all. Even if you don't snowboard, this fun game will be enjoyable as you dodge and jump over obstacles and try to score points along the way. Snowboardmania was created on Microsoft MakeCode Arcade and contains original code with inspiration from other video games such as Temple Run and Club Penguin Hydro Hopper mini game. If you're ready for a snowboarding adventure, click the link in line 12 and follow the easy steps below. 

 To play this 2D Snowboardmania game you need to:
 1. press the play button
 2. press 'A' to jump over the obstacles (logs) and to collect points (snowman)
 3. continue playing for as long as you can
 4. if you hit a log, the game will end and you will finish with the highest score you earned
 5. to replay, repeat steps 1-4

## Use as Extension

This repository can be added as an **extension** in MakeCode.

* open [https://arcade.makecode.com/](https://arcade.makecode.com/)
* click on **New Project**
* click on **Extensions** under the gearwheel menu
* search for **https://github.com/janecroser-hash/creative-coding-a2-snowboardmania** and import

## Edit this project

To edit this repository in MakeCode.

* open [https://arcade.makecode.com/](https://arcade.makecode.com/)
* click on **Import** then click on **Import URL**
* paste **https://github.com/janecroser-hash/creative-coding-a2-snowboardmania** and click import
